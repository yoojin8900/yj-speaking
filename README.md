# YJ 말하기 연습장

YJ ENGLISH 가을 영어 말하기 대회 연습용 웹앱입니다. 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

- 학생: 학년·이름 선택 → 표본 듣기 → 4부분 녹음 → 별점과 피드백 → 전체 읽기
- 채점: 브라우저 음성 인식(발음·완성도)과 공식 음원 비교(억양·속도·쉼)
- 선생님: 비밀번호로 들어가 반 전체 점수, 학생별 성장 그래프, 녹음 듣기, 명단 관리
- 기록 저장: Supabase(`sp_*` 함수만 공개, 표는 비공개). 녹음은 7일 보관

## 파일
- `index.html` — 앱 전체 (HTML·CSS·JS 한 파일)
- `audio/` — 학년별 공식 음원 (전체 + A~D 부분, 64kbps 모노)
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — 홈 화면 설치용
